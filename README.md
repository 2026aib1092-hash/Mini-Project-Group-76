## Project-Overview
The main Objective of this project is to predict the product sales based on advertising spend across multiple marketing channels.
Businesses spend money on different advertising platforms such as TV, Radio, and Newspaper to promote their products. However, it is important to understand how advertising expenditure across these channels affects product sales.

In this project, we use Machine Learning techniques to analyze the relationship between advertising spending and product sales. We train a regression model using historical advertising data to predict sales based on the amount spent on different advertising channels.

The project aims to:
- Analyze the relationship between advertising expenditure and sales.
- Identify which advertising channels influence sales.
- Build a machine learning model to predict product sales.

This project demonstrates how Data Science and Machine Learning can help businesses make better advertising and marketing decisions.
