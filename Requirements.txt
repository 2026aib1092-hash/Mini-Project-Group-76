## Requirements

### Software Requirements
- Python 3.x
- Jupyter Notebook or VS Code
- pip (Python package manager)

### Python Libraries

The following libraries are required to run this project:

Library : Purpose 

NumPy : Numerical operations and sample data generation
Pandas : Loading and processing the advertising dataset
Matplotlib : Creating graphs and visualizations
Scikit-learn : Training and evaluating the Linear Regression model 
OS : Handling file paths and directories (built-in Python module)

### Installation

1. Make sure Python is installed.
2. Install the required libraries using following lines in terminal:

   py -m pip install numpy / pandas/ matplotlib / scikit-learn

3. Make sure the dataset file (Advertising Budget and Sales.csv) is downloaded in the same file as ML_model_prediction.ipynb .
